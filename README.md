# 🌸 Yachiru — Discord бот

Универсальный Discord-бот: экономика с валютой **чирукойны** 🪙, мини-игры,
магазин, пассивный доход, достижения, уровни, квесты, модерация, RP-команды
и ивенты. Всё в одном боте.

## ✨ Возможности

- 💰 **Экономика** — `/work`, `/daily`, `/weekly`, `/crime`, `/heist`, `/beg`, банк, проценты, переводы
- 🎰 **Игры** — блэкджек, слоты, рулетка, кубик, орёл/решка, угадай число, камень-ножницы-бумага
- 🛒 **Магазин** — бонусы к работе, пассивный доход (дома/заводы), расходники, кейсы
- 📈 **Биржа** — акции с меняющимися ценами
- 🎣 **Активности** — рыбалка, шахта, ферма
- ⭐ **Прогрессия** — уровни (XP за сообщения и команды), ежедневные квесты, 10+ достижений
- 🎉 **Ивенты** — дождь денег, редкие события, лотерея (раз в сутки), аукцион
- 🛡️ **Модерация** — бан, кик, мут, роли, автороль, приветствия с баннером
- 💕 **RP-команды** — kiss, hug, punch, slap и другие с аниме-картинками

## 🚀 Быстрый старт (локально)

```bash
# 1. Клонируй репозиторий
git clone https://github.com/ТВОЙ_АККАУНТ/yachiru-bot.git
cd yachiru-bot

# 2. Установи зависимости
pip install -r requirements.txt

# 3. Настрой токен
cp .env.example .env
# открой .env и вставь токен: TOKEN=твой_токен

# 4. Запусти
python bot.py
```

## ☁️ Деплой на BotHost

1. Создай бота на [Discord Developer Portal](https://discord.com/developers/applications)
   и скопируй токен. Включи **Server Members Intent** и **Message Content Intent**.
2. Залей этот репозиторий на GitHub (`git push`).
3. На BotHost: **Create bot** → **Import from GitHub** → выбери репозиторий.
4. В настройках бота укажи **Start command**: `python bot.py`
5. Открой **Environment Variables** и добавь:
   - `TOKEN` = токен твоего бота
6. Запусти. Готово! 🎉

> 💾 Данные хранятся в файле `data.json`, который создаётся автоматически.
> На BotHost файл сохраняется между перезапусками, но для надёжности
> регулярно делай резервные копии или выгружай его себе.

## ⚙️ Первичная настройка на сервере

1. `/help` — список всех команд
2. `/seteventchannel` — канал для ивентов (дождь денег, лотерея, аукционы)
3. `/welcome set channel:#канал text:Добро пожаловать, {user}!` — приветствие
4. `/autorole set role:Новичок` — автоматическая роль

## 🛡️ Требования

- Python 3.9+
- Intents: Server Members, Message Content
- Права бота: Send Messages, Embed Links, Use Slash Commands, Manage Roles (для ролей), Ban/Kick (для модерации)
